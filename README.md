# AVYRN VPN

Одна подписка для Happ с четырьмя режимами:

- Обычные серверы — ручной выбор (150 узлов из актуального источника)
- AUTO — автоматический выбор обычного сервера по минимальному ping
- Белый список — ручной выбор (105 узлов из актуального источника)
- AUTO БС — отдельный автоматический выбор сервера белого списка

## Подписка

Добавить в Happ:
https://raw.githubusercontent.com/e6asos/AVYRN-VPN/main/subscription.json

## Автообновление

GitHub Actions собирает подписку из двух публичных источников каждые 2 часа. Первый запуск уже опубликован; дальнейшие обновления идут автоматически. Ручной запуск: Actions → Update AVYRN VPN → Run workflow.

Публичные серверы могут отключаться между обновлениями. Сборка проверяет структуру и наличие серверов, но не гарантирует доступность каждого узла из конкретной сети.
